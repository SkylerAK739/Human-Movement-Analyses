# Grip Strength Machine Learning Project

## Overview
This project explores the use of machine learning models to predict outcomes related to grip strength performance, using time-series or kinematic features from movement studies.

## Files
- `Grip Strength ML Models.ipynb`: Jupyter notebook for training and evaluating the models. Includes scripts used for cleaning MOCAP data
- `Grip Strength ML Overview.pptx`: Presentation describing methodology, key results, and figures.
- `Mocap_Mallet_Stats copy.xlsx`: Simulated data used for training/testing the model.

## Tools Used
- Python (pandas, scikit-learn, matplotlib)
- Jupyter Notebook / VSCode
- PowerPoint (for visual summaries)

## Key Methods
- Data preprocessing and feature engineering
- Train/test split and model evaluation (e.g., Random Forest, Logistic Regression)
- Accuracy, confusion matrix, and ROC curve visualization

## What I Learned
- Best practices for modeling with small samples
- Communicating model outcomes visually and clearly
